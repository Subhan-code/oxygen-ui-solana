# Oxygen UI Feedback & Community Guidelines

Thank you for using Oxygen UI! Your feedback helps shape the future of Solana frontend component development.

---

## 💬 Submitting Feedback

We welcome feedback, feature suggestions, component requests, and bug reports:

### 1. GitHub Issues & Discussions
- **Bug Reports**: Open an issue on GitHub with a reproduction repo or snippet: [Submit Bug Report](https://github.com/Subhan-code/oxygen_ui/issues/new?template=bug_report.md)
- **Component Requests**: Propose a new Solana or Web3 primitive: [Request Component](https://github.com/Subhan-code/oxygen_ui/issues/new?template=feature_request.md)

### 2. Direct Feedback & Social Channels
- **Twitter / X**: DM or tag Founder [@SubhanHQ](https://x.com/SubhanHQ)
- **Email**: Reach out directly to `syedsubhan.official@gmail.com`

## 🛠️ Contribution Workflow

Oxygen UI is an open community project supported by the Solana Foundation India Grants program.

1. **Fork & Clone**:
   ```bash
   git clone https://github.com/Subhan-code/oxygen_ui.git
   cd oxygen_ui
   npm install
   ```

2. **Develop Component**:
   - Add new component TSX files under `components/ui/`
   - Register in `registry.json`
   - Run `npm run registry:build`

3. **Submit Pull Request**:
   - Follow standard formatting and accessibility rules outlined in [`CONVENTIONS.md`](CONVENTIONS.md).

---

## 📋 Ecosystem Feedback Iteration Process

- **Weekly Triage**: All incoming requests and bug reports are reviewed weekly.
- **RFC & Design**: High-impact Solana primitives (e.g. Blinks/Actions integration, multisig approval cards, transaction simulations) undergo public design review.
